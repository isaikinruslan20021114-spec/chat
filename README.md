# Умный чат — MCP-сервер

Сервер предоставляет два инструмента:

- `get_writing_rules` — возвращает руководство по стилю.
- `review_text` — отмечает некоторые буквальные шаблонные фразы, канцелярит и плейсхолдеры.

Проверка не является AI-детектором и не определяет происхождение текста. Она находит только заданные текстовые паттерны. Смысловую редактуру выполняет модель ChatGPT, опираясь на инструкции сервера и файл правил.

## Локальный запуск

Требуется Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
python server.py
```

MCP endpoint: `http://localhost:8000/mcp`.
Сервер слушает `0.0.0.0` и использует порт из переменной окружения `PORT` (по умолчанию `8000`).

## Развёртывание через Render

В проект добавлен `render.yaml` и Dockerfile.

1. В Render выбрать **New → Blueprint** и подключить этот репозиторий.
2. Render прочитает `render.yaml` и создаст веб-сервис `umny-chat-mcp`.
3. После успешного деплоя скопировать публичный адрес сервиса и добавить к нему `/mcp`.
4. Проверить endpoint через MCP Inspector.

В конфигурации указан платный план Render Starter, чтобы не полагаться на режим сна бесплатного сервиса.

## Подключение к ChatGPT

После развёртывания понадобится добавить сервер как пользовательское MCP-подключение, если эта возможность доступна в настройках аккаунта или рабочего пространства. Указать имя `Умный чат` и адрес `https://ВАШ-ДОМЕН/mcp`. Доступность пользовательских MCP-подключений зависит от тарифа, типа рабочего пространства и актуальных ограничений OpenAI.

Для этой версии инструменты только читают файл правил и анализируют переданный текст; сервер не хранит тексты и не вызывает внешние API.

## Локальная проверка

```bash
python -m compileall -q server.py
```

Дополнительно можно запустить MCP Inspector и подключиться по Streamable HTTP к `http://localhost:8000/mcp`.

## Безопасность и ограничения

- Не добавляйте секреты в GitHub или в Docker-образ.
- В этой версии нет авторизации; не подключайте к серверу приватные базы и не добавляйте инструменты записи без аутентификации.
- `review_text` проверяет только перечисленные фразы. Отсутствие совпадений не доказывает, что текст написан человеком.
- Для публичного каталога понадобится стабильный HTTPS endpoint, проверка требований OpenAI и отдельная процедура отправки на публикацию.
